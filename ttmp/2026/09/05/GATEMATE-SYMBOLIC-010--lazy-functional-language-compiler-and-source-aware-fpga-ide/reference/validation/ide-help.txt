Run the source-aware LFL1 IDE; device loads require an explicit control request

Usage:
  lazy-language-ide [flags]

Flags:
      --config-file string    Explicit config file path to load via middlewares - <string>
      --device string          - <string> (default "/dev/ttyACM0")
      --engine string          - <choice> (model,serial) (default "model")
  -h, --help                  help for lazy-language-ide
      --listen string          - <string> (default "127.0.0.1:18091")
      --log-level string       - <choice> (debug,info,warn,error) (default "info")
      --print-parsed-fields   Print the parsed fields - <bool>
      --print-schema          Print the command's schema - <bool>
      --print-yaml            Print the command's YAML - <bool>
